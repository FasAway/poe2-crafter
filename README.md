# PoE2 混沌石洗练工具

Windows 10/11 桌面工具，面向流放之路2国际服繁体中文。通过游戏复制出的详细装备文本判断词缀；对同一件稀有装备逐次使用混沌石，达到全部指定条件时停止。

当前重写版本：**v0.1.4**。程序与流放之路官方无关联。读取和条件判断已有离线测试，实机兼容性仍随客户端、显示设置和网络响应而变化。

## 功能

- 按详细文本解析前后缀、阶层、破裂、工艺标记和复合属性。
- 区分实际数值与括号中的词缀范围；符文、面板属性和需求不参与可洗词缀判断。
- 繁体关键词、精确阶层或阶层区间，以及实际数值下限。所有条件须同时满足。
- Shift连续使用或每轮重新选通货两种模式。
- 速度倍率0.5至5，以及可关闭的随机额外等待范围。
- 前台窗口检查、客户区坐标校准、剪贴板更新检查、操作后词缀变化验证、次数上限和停止热键。
- 本地诊断导出，无后台上传功能。

## 下载与运行

Windows EXE发布在 [Releases](https://github.com/FasAway/poe2-crafter/releases)，无需安装Python。

如果还未创建新版Release，可在 [Actions](https://github.com/FasAway/poe2-crafter/actions) 的成功构建下下载 `poe2-crafter-windows` Artifact并解压。

从源码运行需要Windows和带Tkinter的Python 3.10+，没有第三方运行依赖：

```powershell
python app.py
```

`python main.py` 也可启动界面。旧版的 `core/`、`gui/`、词缀数据库和爬虫均不再使用。

## 操作步骤

1. 打开游戏背包，把混沌石和未污染的稀有装备放在固定位置。
2. 切到游戏前台按 **F6** 绑定窗口。
3. 鼠标移到混沌石格子中央按 **F7**，移到装备格子中央按 **F8**。只记录坐标，不点击。
4. 按 **F5** 做只读测试，回到工具确认词缀解析正确。装备文本应包含 `{ 前綴…階層… }` 等详细标记。
5. 添加停止条件。点击词缀表中的行可以填入对应属性模板，随后修改阶层或数值。
6. 第一次将最大次数设为 **1**，回到游戏按 **F9** 开始，确认实际使用与读取均正常后再增加次数。
7. **F10** 停止，切换到其他窗口也会停止。每次启动重新计算本轮次数。

界面的“开始”和“只读测试”按钮有3秒延迟，用于切回游戏。若默认Ctrl+C无法复制详细属性，可选择Ctrl+Alt+C，随后重新做只读测试。通货不通过剪贴板识别；F7位置必须放置混沌石。

绑定后窗口移动会转换坐标，窗口尺寸变化则须重新绑定校准。运行期间不要移动装备或改变背包布局。仅检查基底、类别和物等不能区分两件完全同类的装备。

## 停止条件示例

| 类型 | 繁体关键词 | 阶层 | 数值≥ | 含义 |
| --- | --- | --- | --- | --- |
| 后缀 | 攻擊速度 | 1-3 | 留空 | T1、T2、T3任一阶都接受 |
| 后缀 | 攻擊速度 | 1 | 28 | 同一条词缀为T1且实际数值至少28 |
| 前缀 | 最大生命 | 留空 | 100 | 不限阶层，实际生命值至少100 |

填 `3` 只接受T3；填 `1-3` 或 `T1-T3` 接受闭区间；留空不限。多个不同条件仍须同时满足，不要分别添加T1、T2、T3来表示任一阶。

`附加2(1-2)至5(3-5)火焰傷害` 的实际数值是2和5。设置数值下限时，填写“数值位置”：1代表下限2，2代表上限5。缺少阶层或多数值有歧义时会停止，需要明确条件。

第一版不支持OR条件分组、排除条件、自动换装备、预兆、自动补货或其他通货。

## 连续使用与速度

默认连续模式先按住Shift、右键选中一次混沌石，然后逐次左键装备，每次之后复制并判断。达标、次数用尽、停止或异常时释放Shift。取消勾选可改为每轮重新选通货。停止后若光标仍带通货，请手动右键取消选中。

速度默认3倍，1对应旧版基础等待；倍率越高等待越短，输入与读取保留最短等待。随机额外延迟默认每次使用前50至150毫秒，可修改范围或关闭。设置下次启动时生效，随机范围不随速度缩短。实际速度取决于游戏和剪贴板响应；加速后若频繁出现词缀未变化或复制失败，请降低倍率。

每次使用仍验证装备变化。若无变化会停止，而不会自动重复点击；这也可能来自正常随机过程。最大次数表示发送的操作次数，不能证明实际消耗量。工具不计算通货库存。

随机延迟只改变节奏，不能保证自动操作不被识别，也不提供规避检测功能。

## 排查问题

- “粘贴剪贴板并解析”可单独测试文本，不操作游戏，但不能替代F5实机只读测试。
- 若游戏以管理员运行而输入无效，检查游戏与工具的权限级别。
- “导出诊断”保存到 `Documents/PoE2Crafter/diagnostics`。文件包括窗口信息、坐标、条件、速度配置、最近装备文本和日志，不自动上传。
- 样本 `sample_item.txt` 带污染标记，用于解析测试，工具会拒绝继续对它使用混沌石。

## 测试与打包

Windows下运行离线测试，测试不会发送真实游戏输入：

```powershell
python -m unittest discover -v
```

当前33项测试覆盖解析、阶层区间、停止条件、连续模式、随机等待中断和快速模式的剪贴板检查。

打包：

```powershell
python -m pip install -r requirements-build.txt
python -m PyInstaller --noconfirm build.spec
```

生成 `dist/PoE2Crafter.exe`。GitHub Actions会在main更新、PR、v开头的标签推送或手动运行时执行测试、打包和隐藏窗口自检，成功后提供EXE及源码ZIP供下载。CI不验证实际游戏输入。
